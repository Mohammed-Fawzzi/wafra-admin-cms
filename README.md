# وفرا — لوحة إدارة المنصّة

حزمة كاملة: وثيقة المتطلبات + نموذج الشاشات (48 شاشة، 22 نافذة منبثقة) + ملفات المصدر.

آخر تحديث: 8 سبتمبر 2026

> **تصحيحان مطبَّقان في هذه النسخة:**
> 1. الفروع والحجوزات مرتّبة تحت شركات المزوّدين، لا كقوائم مسطّحة على مستوى المنصّة.
> 2. إضافة السيارة أو الفرع لا تحتاج اعتماد الإدارة — تُنشر مباشرة، والرقابة لاحقة.
> 3. الجداول تفاعلية فعلياً: فلاتر وبحث وتبويبات وترقيم صفحات وإجراءات صفوف.
>
> الوثيقة (docx) لم تُزامَن بعد مع هذين التصحيحين: البنود `FR-ADF-01` و`FR-ADF-05`
> و`FR-ADB-01` و`FR-ADX-02` تحتاج إعادة صياغة.

## 1. للمشاركة والمراجعة

```
deliverables/wafra-admin-screens-static.html
```

**هذا هو الملف الذي ترسله للآخرين.** كل الشاشات مكتوبة داخله كـHTML فعلي ولا يحتاج
تشغيل جافاسكربت، فيعمل في أي عارض. التنقّل من القائمة على اليمين.

لتصدير كل الشاشات كـPDF: افتحه ثم اطبع (Ctrl+P) واختر "حفظ كـPDF" — كل شاشة
تخرج في صفحة مستقلة بلا شريط جانبي.

> **ملاحظة مهمّة عند الإرسال:** بعض المنصّات (Google Drive، واتساب، معاينة مرفقات
> البريد) تعرض ملفات HTML كنص خام أو ترفض فتحها. الأضمن: رابط مباشر من Dropbox أو
> OneDrive بخيار "فتح في المتصفح"، أو إرسال الـPDF المطبوع، أو استضافة الملف على
> GitHub Pages أو Netlify Drop (كلاهما مجاني ويقبل رفع ملف واحد بالسحب).

### إعادة البناء بعد أي تعديل

ترتيب الدمج مُلزم — `p4` أخيراً لأنه يحوي الموجّه، و`p1` أولاً لأنه يعرّف المكوّنات:

```bash
cat src/p1.html src/p2.html src/p3.html src/p5.html src/p6.html src/p7.html src/p4.html src/p8.html src/p9.html src/p10.html src/p11.html src/p12.html \
    > deliverables/wafra-admin-screens.html
```

ثم توليد النسخة الثابتة (تتطلّب Python و Playwright):

```bash
pip install playwright && playwright install chromium
python tools/build_static.py
```

السكربت يفتح النسخة التفاعلية، يستخرج HTML كل شاشة ونافذة بعد تنفيذها، ويجمعها
في ملف ثابت مع تنقّل يعتمد على `:target` بلا أي جافاسكربت، ويضمّن معه طبقة
التفاعل: فإن كان جافاسكربت مفعّلاً عملت الفلاتر والتبويبات، وإن كان معطّلاً بقي
الملف مقروءاً بالكامل.

## التفاعل

`p6` طبقة عامة تعمل على أي جدول دون ربط يدوي: تقرأ عناوين الأعمدة، تبني خيارات
كل فلتر من قيم عموده، وتطبّق التبويب والبحث والفرز والترقيم معاً. لذلك أي جدول
جديد يُضاف يصبح تفاعلياً تلقائياً.

**الفلاتر التي لا يقابلها عمود في الجدول تُحذف من الواجهة عند التشغيل** بدل أن
تبقى معطّلة. إن أردت إبقاء فلتر منها فأضف عموده إلى الجدول.

### توليد وثيقة الـWord

```bash
npm install docx && node tools/build.js
```

`tools/content.js` يحوي نصّ كل المتطلبات كمصفوفات — عدّله لتحديث الوثيقة.

## 5. طبقة التفاعل

`src/p6.html` يعمل على الـDOM بعد رسم الشاشة، دون أن تعرف الشاشات بوجوده. لذلك أي
جدول جديد تضيفه يصبح تفاعلياً تلقائياً بلا كتابة سطر إضافي:

- **الفلاتر** تبني خياراتها من قيم العمود المطابق لاسم الفلتر فعلياً، فلا تظهر خيارات
  لا وجود لها في البيانات. في الجداول المجمّعة، فلتر «المزوّد» يعمل على رأس المجموعة.
- **البحث** فوري على كل نصّ الصف، **والتبويبات** تطابق بجذر الكلمة (تبويب «حسّاسة»
  يلتقط شارة «حسّاس»).
- **الترقيم** حقيقي مع تغيير عدد الصفوف، وحالة «لا توجد نتائج» تظهر تلقائياً.
- **إجراءات الصفوف** مربوطة بالأيقونة: 👁 معاينة · ✎ تعديل · ⏸ إيقاف · ▶ تفعيل ·
  🗑 حذف · ⤫ إخفاء · ⚑ ملاحظة · ✉ إعادة إرسال · ✓ اعتماد. نافذة المعاينة تُبنى من
  ترويسات الجدول وقيم الصف، فتبقى صحيحة مهما تغيّرت الأعمدة.

النسخة الثابتة تحمل هذه الطبقة أيضاً: المحتوى يظهر بلا جافاسكربت، والتفاعل يضاف
فوقه إن كان مفعّلاً.

## 6. نظام التصميم

مأخوذ من صفحة `Design System` في ملف Figma، مع الإبقاء على هوية وفرا.

| | |
|---|---|
| الكحلي | `#22386F` — توكن `Buttons/secondary/default` |
| المرجاني | `#F04E37` — لون الإجراء الأساسي |
| الذهبي | `#F1C111` — دلالة التنبيه والانتظار فقط |
| النصوص | `#111217` · `#444A5B` · `#666F89` · `#90949E` · `#C3C6D2` |
| الخلفيات | `#FFFFFF` · `#FAFAFB` · `#E4E5EB` |
| الحدود | `#D3D6DE` · `#C3C6D2` |
| النجاح / الخطأ / المعلومة | `#00AD5F` · `#F50202` · `#428BC1` |
| نصف القطر | 2 · 4 · 6 · 10 · 16 · 24 · 36 · 999 |
| الظلال | small · medium · large · xlarge بقيم `rgba(16,24,40,.1)` |
| الخط | Expo Arabic (الأزرار: Bold 14/14) |

**تنبيه على الخط:** Expo Arabic خط مرخّص وغير متاح على أي CDN عام. الملفات تشير
إليه أولاً وتسقط تلقائياً إلى Tajawal ثم Cairo. للتسليم النهائي ستحتاج نسخة ويب
مرخّصة منه.

**تنبيه على التباين:** درجات الألوان الأصلية من نظام التصميم لا تجتاز معيار
WCAG AA على خلفياتها الفاتحة عند حجم 12px. أبقيت درجات النظام للنقاط والأشرطة
والرسوم، واشتققت درجة أغمق للنص داخل الشارات فقط.
